FF Research — draft room companion
==================================

1. Start the helper:   python3 draft_sync.py --room-only
   (or plain `python3 draft_sync.py` for your real draft — it uses both sources)

2. Chrome bookmark bar → right-click → Add page. Name it "FF Draft".
   Paste EVERYTHING below the dashed line as the URL.
   NOTE: if Chrome strips the leading `javascript:` when you paste, type those
   ten characters back in by hand. It does this silently and the bookmark then
   does nothing at all.

3. Open your ESPN draft room and click the bookmark ONCE.
   A small "FF Research sink" window opens — leave it open, shove it in a corner.
   Chrome blocks an HTTPS page from reaching a local server directly, so that
   window is how picks get through. A badge appears bottom-right; click it to stop.

If Chrome blocks the popup, allow popups for espn.com and click the bookmark again.
